# Antigravity Auto-Accept IDE Extension

Official status bar integration and auto-accept controller for Antigravity IDE.

## Features
- **Bottom Status Bar Toggle**: Displays `⚡ Auto-Accept: ON` / `$(circle-slash) Auto-Accept: OFF` directly in the IDE's bottom right status bar.
- **One-Click Toggle**: Click to seamlessly pause or resume auto-accept.
- **Cross-App Sync**: Automatically synchronizes state with Antigravity Desktop app and the CLI daemon.
- **Commands**:
  - `Antigravity Auto-Accept: Toggle Auto-Accept`
  - `Antigravity Auto-Accept: Enable Auto-Accept`
  - `Antigravity Auto-Accept: Disable Auto-Accept`
